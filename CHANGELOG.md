# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-25

Первый публичный релиз (MVP по ТЗ «Школа кураторов»).

### Добавлено
- **F1** Онбординг и профиль: отделение → группа → интересы → цель, согласие на обработку ПД.
- **F2** Свободные часы на скользящую неделю и защищённый внеучебный час.
- **F3** Лента мероприятий по интересам/тегам (переключатель «по интересам / все»).
- **F4** Карточки ценности мероприятия: навык, баллы, портфолио.
- **F5** Запись на мероприятие с подсветкой пересечений с парами и защищённым окном.
- **F6** Тайм-менеджмент: «3 горизонта» и «Учебные цели» с мини-заданием.
- **F7** Контакты кураторов отделения.
- **F8** Кабинет организатора: ввод и редактирование мероприятий, счётчик записей.
- **F9** Админка: загрузка расписания (CSV), теги/группы/кураторы, защищённое окно, модерация, выдача ролей.
- Telegram Mini App (vanilla JS) + бот на aiogram 3 + API на FastAPI / async SQLAlchemy.
- Авторизация по Telegram `initData` (HMAC), роли `student` / `organizer` / `admin`.
- Docker Compose (PostgreSQL + API + бот), локальный запуск на SQLite, демо-данные ЭМИТ.
- Тесты (pytest) и CI в GitHub Actions.

> Не является официальным продуктом РАНХиГС.
